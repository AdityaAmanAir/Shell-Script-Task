## How to run the scripts:
1. Clone the repository to your local machine using the command:
   ``` git clone https://github.com/AdityaAmanAir/Shell-Script-Task ```
2. Navigate to the cloned directory:
   ``` cd Shell-Script-Task ```
3. Make the scripts executable by running:
   ``` chmod +x script_name.sh ```
4. Run the desired script using the command:
   ``` ./script_name.sh ```

Make sure to replace `script_name.sh` with the actual name of the script you want to execute.

## Required Tools:
- Bash shell (available on most Unix-like operating systems)
